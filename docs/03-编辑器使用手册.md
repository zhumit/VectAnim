# 编辑器使用手册

> [English](en/03-editor-user-guide.md) | 中文

打开 `dist/editor/index.html`（或开发模式 `npm run dev` 后访问 http://localhost:5173）即可使用。编辑器是**纯前端**：不依赖后端，文件读写都在本地完成。

---

## 1. 界面布局

```
┌──────────────────────────────────────────────────────────────────────┐
│ 顶栏：文件 / 撤销重做 / 缩放 / 网格吸附 / 导出图片 / 实时预览 / 帮助   │
├────┬──────────────┬───────────────────────────────┬──────────────────┤
│ 工 │ 图层            │                               │ 属性 / 变量 / 动画 │
│ 具 │ （分组 + 图形）  │        画布（Fabric）          │                  │
│ 栏 │               │                               │                  │
├────┴──────────────┴───────────────────────────────┴──────────────────┤
│ 状态栏：坐标 / 选中数量 / 图形与变量统计 / 历史深度 / 缩放比例          │
└──────────────────────────────────────────────────────────────────────┘
```

- **画布**：中间白色区域就是导出的画布范围，深色区域是工作区。滚轮平移，`Ctrl+滚轮` 缩放，空格 + 拖动临时平移。
- **图层**：分组在上、未分组图形在下；按 ZIndex 从上到下排列。眼睛图标切换显隐，双击名称重命名。
- **右侧面板**：`Properties`（几何/外观/变换/绑定）、`Variables`（变量表 + 实时值滑杆）、`Animations`（表达式 + 关键帧时间轴）。

## 2. 绘图

| 工具 | 快捷键 | 操作 |
| --- | --- | --- |
| 选择 | `V` | 点选、框选（空白处拖动）、拖动、缩放（角点）、旋转（上方控制点） |
| 直线 | `L` | 按下拖动到终点 |
| 矩形 | `R` | 拖动框选；按住 `Shift` 画正方形（松手后保持正方形） |
| 椭圆 | `E` | 拖动框选；按住 `Shift` 画圆（松手后保持正圆） |
| 半圆弧 | `A` | 拖动确定**直径**（起点→终点即弦），半径 = 弦长/2；`Shift` 把直径方向锁到 45° 步进，`Alt` 翻转弧线凸起方向 |
| 多边形 | `P` | 逐点点击，`Enter` 或双击闭合（至少 3 点） |
| 钢笔 | `N` | 逐点点击生成**平滑曲线**（Catmull-Rom → 贝塞尔） |
| 自由绘制 | `F` | 按住拖动画任意曲线，松手自动简化 + 平滑 |
| 平移 | `H` | 拖动画布 |

半圆弧生成的是 `Path` 图元（`M` + `A` 指令，默认不填充），因此支持属性绑定、缩放旋转与 WPF 端 `Geometry.Parse` 的原生渲染；后续想变成半圆面，在属性面板把填充色打开即可。

绘图时默认开启**网格吸附**与**对象吸附**（对齐到其它图形的边/中线），可在顶栏用磁铁按钮关闭；网格显示用网格按钮切换。

> 吸附容差固定为 6 屏幕像素，缩放后仍然跟手。

## 3. 编辑操作

| 操作 | 快捷键 |
| --- | --- |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`） |
| 复制 / 粘贴 / 原地复制 | `Ctrl+C` / `Ctrl+V` / `Ctrl+D` |
| 拖动复制 | 按住 `Ctrl` + 拖动已选中的图形：原图形留在原位，副本跟着鼠标走，松手落定；拖动途中先松开 `Ctrl` 则取消复制 |
| 全选 | `Ctrl+A` |
| 删除 | `Delete` / `Backspace` |
| 组合 / 取消组合 | `Ctrl+G` / `Ctrl+Shift+G` |
| 上移一层 / 下移一层 | `Ctrl+]` / `Ctrl+[` |
| 置顶 / 置底 | `Ctrl+Shift+]` / `Ctrl+Shift+[` |
| 微移 | 方向键 1px，`Shift+方向键` 10px |
| 适应窗口 | `Ctrl+0` |
| 放大 / 缩小 | `Ctrl+=` / `Ctrl+-` |
| 导出 JSON | `Ctrl+S` |
| 打开 | `Ctrl+O` |
| 新建 | `Ctrl+N` |
| 实时预览 | `F5` |
| 帮助 | `F1` |

多选后右侧属性面板会出现**对齐 / 等距分布 / 翻转 / 组合**工具条。

**粘贴会相对原位置错开**：每次粘贴偏移 16px，连续粘贴依次累加（`Ctrl+C` 会重置这个累计），所以复制出来的图形不会和原图形重叠；`Ctrl+D` 原地复制同样带 16px 偏移。

**组合 = 一个整体**：`Ctrl+G` 组合后，在画布上点中组内任意成员都会选中整组，拖动、缩放、旋转、方向键微移、删除都作用于整组；`Ctrl+Shift+G` 取消组合后恢复单独选择。图层面板里点击组内的**单个图形行**仍可只选中该图形，方便单独改属性。

### 框选（矩形选择）

在选择工具下，**在画布空白处按住鼠标左键拖动**即可拉出矩形选择框：

| 操作 | 效果 |
| --- | --- |
| 空白处拖动 | **框选**：包围盒与框相交的图形被选中（碰到即选中），虚线框实时预览 |
| `Shift` / `Ctrl` + 点击 | **多选**：加选 / 减选（点已选中的图形即取消它） |
| `Shift` + 拖动 | 框选结果**叠加**到当前选择 |
| 空白处单击 | 清空选择 |

> 框选必须从**空白处**起手；如果起手点落在某个图形上（例如铺满画布的底板），拖动的是那个图形而不是框选。想框选整块画布，从画布外的工作区起手拉框即可。

## 4. 变量

`Variables` 标签页 → 右上角 `+`（`Add variable`）新建。

每个变量可设置：名称、默认值、最小/最大、单位、备注。名称必须满足 `^[A-Za-z_][A-Za-z0-9_]*$`，因为表达式要引用它。

- **重命名会同步改写所有引用**：图形绑定、表达式文本、动画目标变量都会一起更新（按标识符边界匹配，不会误改 `RPMTotal` 里的 `RPM`）。
- **删除变量前会提示引用位置**，删除后相关绑定回落为常量 0，相关动画被移除。
- 变量卡片下方的滑杆写入的是「外部值」，等价于 WPF 端 `SetVariable`，可用来验证数据驱动效果；`External write` 标记表示该变量当前被外部接管。

## 5. 属性与绑定

选中图形后，属性面板按 `Geometry / Appearance / Transform / Variable bindings` 分组。

每个可动画属性右侧都有**链接图标**：

1. 点击 → 弹出变量列表；
2. 选择变量 → 该属性变为绑定（输入框锁定并显示紫色，实时显示变量当前值）；
3. 选择「`New variable and bind…`」→ 直接为该属性创建一个同名变量并绑定；
4. 选择「`Unbind`」→ 回落为常量。

绑定后的行为：

- 画布上该图形会**跟随变量实时变化**；
- 对应的手动操作会被**锁定**，避免互相打架：
  - 位置类属性被绑定 → 禁止拖动
  - 尺寸类属性被绑定 → 禁止缩放
  - 旋转角度被绑定 → 禁止旋转
- `变量绑定` 分组列出该图形的全部绑定，可一键解除。

### 颜色绑定

颜色属性也能绑定变量，但变量是数值，因此约定：**数值按 `0xRRGGBB` 整数解释**。

```
LampColor = 0x00FF00 → 绿色
LampColor = 0xFF0000 → 红色
```

配合表达式即可做报警灯：

```
if(Alarm > 0.5, 16711680, 65280)
```

### 5.1 多选：公共属性批量设置

选中 2 个以上图形（`Shift`/`Ctrl` 点击，或框选）时，属性面板会列出这些图形**共有的属性**（如 `Fill`、`Stroke`、`Stroke width`、`Opacity`、`Rotation` 等），改动会一次性作用到所有选中图形：

- 取值不一致的属性显示为 `Mixed`，在输入框里填新值才会统一；
- 属性右侧的链接图标同样可以**批量绑定**到同一个变量，或批量解除绑定；
- `Variables in the selection` 分组列出选中图形用到的变量及其影响范围；
- 下方仍是 `Align`（对齐/等距/翻转）与 `Organize`（组合/层级/复制/删除）。

> 只列出「所有选中图形都有」的属性：例如同时选中矩形和多边形时，不会出现只属于矩形的 `Width`。

### 5.2 分组：把组合当成一个图形

选中一个分组的全部成员（在图层面板点分组标题即可）时，属性面板切换为**分组模式**：

- **`Group transform`**：`Offset X/Y`（整体平移）、`Rotation`（绕组合中心整体旋转）、`Scale X/Y`（整体缩放），
  以及右侧的 `Rotate −90° / +90° / Reset / Reset transform` 快捷按钮；
- **`Appearance`**：`Opacity`，与每个成员自身的不透明度相乘；
- **`Members`**：列出成员，点击某一行可单独选中该图形；
- **`Variable bindings`**：分组自身的绑定，可一键解除；
- **`Organize`**：取消组合、置顶/置底、翻转。

这些属性和普通图形一样**可以绑定变量**，因此也能被表达式动画、关键帧动画驱动 —— 例如把一个变量绑到分组的
`Rotation`，整个组合就会跟着转。

两点需要注意：

- 在画布上直接拖动/缩放/旋转分组时，改动仍然**烘焙进每个成员的几何**（与以前一致），分组变换保持恒等；
  分组变换是一层**叠加**在成员之上的偏移，用于绑定与动画。
- 分组变换的旋转/缩放中心第一次设置时自动取组合包围盒中心，之后保持不变。

## 6. 动画

`动画` 标签页包含两类动画，可以同时存在。

选中图形（或分组）时，面板顶部会出现 **`Related to the selection`** 分组，列出驱动当前选中对象的动画（按绑定到的变量匹配），点一行即可跳到对应动画卡片。

### 6.1 表达式动画

适合实时驱动（转速、角度、位移）。填写：

- **目标变量**：结果写回哪个变量
- **表达式**：如 `RPM * 6 * t`（`t` 为秒）
- **取模**：如 `360`，让角度循环，避免浮点累积误差

输入框下方会实时显示语法校验结果：`✓ 语法正确 · 使用时间 t · 依赖 RPM`，或标红的错误信息与位置。

### 6.2 关键帧动画

- 时间轴上**点击空白处**新增关键帧；
- 拖动菱形调整时间；
- 双击菱形编辑精确时间/数值/缓动；
- 右键删除关键帧；
- 勾选「`Loop`」，右侧数字为循环间停顿秒数。

时间轴长度 = 最后一个关键帧的时间。

## 7. 实时预览

点击顶栏 `Live preview`（`F5`）：

- 用与 WPF 端**同一套语义**的运行时驱动预览画布；
- 可播放/暂停/停止、拖动时间轴；
- 右侧变量滑杆可实时注入数值，等价于 PLC 写入；
- 底部显示运行时告警（未定义变量、表达式错误、循环依赖等）。

> 预览与编辑器共享同一份变量表：预览里拖动滑杆，编辑器画布上的绑定图形也会同步变化。

## 8. 导入 / 导出

| 操作 | 说明 |
| --- | --- |
| 打开 `.vectanim.json` | 支持拖拽文件到窗口；有错误会弹出问题清单 |
| 导入 SVG | 矩形/圆/椭圆/多边形/折线/路径转为原生图形（文本、图片会跳过并提示） |
| 导出 `.vectanim.json` | 导出前做严格校验，有错误会阻止导出并列出问题 |
| 导出 PNG | 2 倍分辨率，当前变量值快照 |
| 导出 SVG | 矢量快照，便于插入文档/PPT |

**自动保存**：编辑内容会写入浏览器 localStorage（防崩溃丢失），下次打开自动恢复。点击「`New document`」会提示覆盖。

## 9. 常见问题

**Q：画布上的图形动不了？**
A：该属性的位置/尺寸/角度被变量绑定了。到「`Variable bindings`」里解除，或直接改变量值。

**Q：导出的 JSON 在 WPF 里不显示？**
A：先看 WPF 端 `ValidationIssues` / `RuntimeWarnings`；最常见是路径数据非法或画布尺寸为 0。

**Q：为什么导出的 JSON 里没有 `Scale`？**
A：编辑器会把缩放烘焙进几何（宽高/半径/顶点/路径坐标），保证 WPF 端读到的尺寸是真实值。详见 `02-Schema规范.md` 第 10 节。

**Q：颜色透明度不对？**
A：文档约定 `#AARRGGBB`（alpha 在前），与 CSS 的 `#RRGGBBAA` 相反。编辑器会自动转换，手写文件时注意顺序。

**Q：撤销记录太多？**
A：连续拖动同一属性会合并为一条历史（700ms 窗口），最多保留 120 条。
