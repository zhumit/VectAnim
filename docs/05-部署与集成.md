# 部署与集成

> [English](en/05-deployment-and-integration.md) | 中文

## 1. 环境要求

| 用途 | 要求 |
| --- | --- |
| 构建编辑器 | Node.js ≥ 20.19（开发使用 22.x） |
| 构建 WPF 类库 | .NET SDK 8.0+（开发使用 9.0 SDK，目标框架 net8.0-windows） |
| 运行 WPF 控件 | .NET Desktop Runtime 8.0+（或 .NET Framework 4.8，见第 5 节） |
| 浏览器 | Chrome / Edge 90+（需要 Canvas2D 与 ES2022） |

> 本仓库的所有依赖都安装**在项目目录内**：
> - npm 依赖 → `node_modules/`，npm 缓存 → `.cache/npm/`
> - NuGet 包 → `.cache/nuget/packages/`（见 `nuget.config`）
>
> 不会污染机器全局环境，卸载时删除目录即可。

## 2. 构建

```bash
# 一次性安装前端依赖
npm install

# 编辑器：类型检查 + 单元测试 + 生产构建
npm run editor:check
# 产物：dist/editor/（index.html + assets/*.js + assets/*.css，可直接静态托管）

# WPF：构建 + 单元测试 + 离屏渲染验证 + 打包 NuGet
npm run dotnet:build
npm run dotnet:test      # 62 项逻辑测试
npm run dotnet:probe     # 渲染探针：出图 + 像素断言 + 性能
npm run dotnet:pack      # 产物：artifacts/nuget/VectAnim.Wpf.1.0.0.nupkg

# 全部串起来
npm run all
```

开发模式：

```bash
npm run dev              # http://localhost:5173
dotnet run --project dotnet/VectAnim.Demo/VectAnim.Demo.csproj
```

## 3. 编辑器部署

编辑器是纯静态站点，`dist/editor/` 直接放到任意静态服务器即可（`base: './'` 使用相对路径，放在子目录也能跑）。

### Nginx

```nginx
server {
    listen 80;
    server_name vectanim.example.com;

    root /var/www/vectanim;
    index index.html;

    # 单页应用：所有未命中路径回落到 index.html
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 静态资源长缓存（文件名带 hash）
    location /assets/ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    gzip on;
    gzip_types text/css application/javascript application/json image/svg+xml;

    # .vectanim.json 需要正确的 MIME 与 UTF-8
    location ~* \.json$ {
        charset utf-8;
        add_header Cache-Control "no-cache";
    }
}
```

### IIS / 静态托管

- 确认 `.json` 的 MIME 为 `application/json`；
- 若放在子路径（如 `/editor/`），无需改配置，相对路径已处理。

### 离线使用

编辑器不需要后端，可以：
- 直接双击 `dist/editor/index.html`（`file://` 打开）—— 注意此时浏览器可能限制 `localStorage` 与下载，建议用本地静态服务器；
- 打包成 Electron / WebView2 壳，做内网离线工具。

## 4. WPF 集成

### 4.1 NuGet 包（推荐）

```bash
npm run dotnet:pack
# 生成 artifacts/nuget/VectAnim.Wpf.1.0.0.nupkg
```

在目标工程中：

```xml
<PackageReference Include="VectAnim.Wpf" Version="1.0.0" />
```

或将 `.nupkg` 放入本地源：

```xml
<!-- nuget.config -->
<packageSources>
  <add key="local" value="D:\nuget-local" />
</packageSources>
```

### 4.2 项目引用

```xml
<ItemGroup>
  <ProjectReference Include="..\VectAnim.Wpf\VectAnim.Wpf.csproj" />
</ItemGroup>
```

### 4.3 直接引用 DLL

把 `VectAnim.Wpf.dll` 复制到目标工程 `libs/`：

```xml
<ItemGroup>
  <Reference Include="VectAnim.Wpf">
    <HintPath>libs\VectAnim.Wpf.dll</HintPath>
  </Reference>
</ItemGroup>
```

### 4.4 文档文件随程序发布

```xml
<ItemGroup>
  <Content Include="panels\**\*.vectanim.json" CopyToOutputDirectory="PreserveNewest" />
</ItemGroup>
```

```csharp
Viewer.Source = Path.Combine(AppContext.BaseDirectory, "panels", "gear-demo.vectanim.json");
```

或从资源/数据库加载：

```csharp
var json = File.ReadAllText(path);           // 或从数据库/网络读取
Viewer.LoadFromString(json, "db:panel-42");
```

## 5. .NET Framework 4.8 支持

类库目标框架是 `net8.0-windows`。若现场必须是 .NET Framework 4.8：

1. 新建 `net48` 类库工程，把 `dotnet/VectAnim.Wpf` 下的源码（`Model` / `Expressions` / `Animation` / `Runtime` / `Rendering` / `Controls`）整体链接进去；
2. 把 `System.Text.Json` 换成 `Newtonsoft.Json`：需要为 `ValueRef` 写一个 `JsonConverter`（结构见 `ValueRefJsonConverter`），或在 `Model` 上改用 `[JsonProperty]`；
3. 其余代码（WPF 渲染、表达式引擎、动画调度）不依赖 .NET Core 特性，可直接编译（`Math.Clamp` 需要替换为手写实现，`record struct` 需改为普通 struct）。

> 之所以默认 net8.0：`System.Text.Json` 内置、性能更好、无需第三方包。若确需 net48，建议优先考虑升级到 .NET 8 —— 后者仍在长期支持期内。

## 6. 运行期集成模式

### 6.1 PLC / OPC 采集线程

```csharp
public sealed class PlcBridge : IDisposable
{
    private readonly VectAnimViewer _viewer;
    private readonly CancellationTokenSource _cts = new();

    public PlcBridge(VectAnimViewer viewer)
    {
        _viewer = viewer;
        _ = Task.Run(PollAsync);
    }

    private async Task PollAsync()
    {
        while (!_cts.IsCancellationRequested)
        {
            var snapshot = new Dictionary<string, double>
            {
                ["RPM"] = await ReadTagAsync("DB1.DBD0"),
                ["Temp"] = await ReadTagAsync("DB1.DBD4"),
            };

            _viewer.SetVariables(snapshot);   // 线程安全，内部合并为一次重绘
            await Task.Delay(100, _cts.Token);
        }
    }

    private Task<double> ReadTagAsync(string tag) => Task.FromResult(0d);

    public void Dispose() => _cts.Cancel();
}
```

### 6.2 多画面切换

```csharp
// 预加载多份文档，切换时只换 Source（或直接 LoadFromString 命中缓存）
Viewer.Source = Path.Combine(baseDir, "panels", "line-1.vectanim.json");
```

> 每次加载都会重建渲染状态。若画面切换频繁（< 1s 一次），建议**预建多个 Viewer** 放在 `Grid` 里切换 `Visibility`，避免重复解析。

### 6.3 点击交互与告警弹窗

```xml
<va:VectAnimViewer x:Name="Viewer" ShapeClick="OnShapeClick" />
```

## 7. 版本升级策略

- `SchemaVersion` 采用 `主.次` 语义：`1.x` 内保持向后兼容（只增字段，不改语义）；
- 运行时读取时对 `1.*` 全部接受，对 `2.x` 给出告警并尽力解析；
- 编辑器导出的永远是 `1.0`，扩展字段（`Opacity`/`LineCap`/`Scale` 等）缺省即默认行为，旧运行时读新文件不会画错，只是忽略新特性。
